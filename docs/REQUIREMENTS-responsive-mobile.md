# 需求书：QuotaHub 前端移动端响应式改造（2026-10-17）

> 来源：用户「把响应式不友好的项目都改造一下」。审计口径：真浏览器 390×844 + 生产后端真实数据（本地注入 `X-Auth-User` 的预览代理）。

## 0. 硬约束（违反即返工）

- **只动前端**（`web/`）：不得改后端、不得改 HTTP 契约与路由（硬约束 1）、不得改采集语义（硬约束 2）、不得改库结构（硬约束 3）。
- **不得修改 `/root/proj/quotahub`（旧实现，只读）、不得重启 `quotahub.service`、不得写它的现网库**。
- **设计语言**：Ant Design 默认设计语言（默认主色 `#1677ff`、圆角 6px、系统字体栈）；不得把自定义配色映射进 antd token。图表用现有 ECharts 按需引入方式。
- **不得引入新的 UI/路由/状态库**。
- **桌面观感必须不变**：≥992px 逐像素一致（断点只在窄屏/`pointer: coarse` 生效）。
- 禁 emoji；文案克制；不隐藏导航（窄屏用抽屉/折叠）。
- 源码/配置/文档/提交信息不得出现真实域名、公网 IP、邮箱、密钥、口令、真实平台 key；示例统一 `example.com` / `127.0.0.1`。
- 小步中文提交、不带署名、**不 push**、不开分支、不 `git add` 运行产物。
- 禁止改 nginx/systemd、不许动 `/var/www`。

## 2. 要做的

1. **触摸目标**：窄屏/`pointer: coarse` 下主要按钮 ≥44px、次要图标按钮 ≥32×32、行内相邻按钮间距 ≥8px；桌面尺寸不变。
2. **表单控件**：输入框/选择器 ≥44px 高、字号 ≥16px（注意 antd Select 的实际命中区是 `.ant-select-selector`，`min-height` 会被 antd 的固定 `height` 影响，务必实测内层高度）。
3. **巡视所有视图**（看板 / 平台配置 / 历史 / 设置 / 登录页），逐屏确认：无 <12px 可见文本、无 <44px 主要操作、无横向溢出；**ECharts 图在窄屏不溢出**（`resize` 已有的话确认容器宽度自适应）。
4. **窄屏排版**：卡片/工具条换行或折叠，长平台名不撑破卡片。
5. **导航**：窄屏不得隐藏导航（抽屉/折叠）。
